## 🧬 My Automation Blueprint

Every system I build follows the same reliability-first pattern:

```mermaid
flowchart LR
    T["⏰ Trigger<br/>schedule · webhook · sheet row"] --> D["🔎 Discover & Ingest<br/>APIs · browser automation"]
    D --> S[("🗄️ State Store<br/>deduped · resume-safe")]
    S --> L["🧠 AI Layer<br/>Claude · FLUX · LTX-Video"]
    L --> R{"⚖️ Rules & Scoring<br/>deterministic gates"}
    R -->|pass| H["👤 Human-in-the-loop<br/>approve · draft only"]
    R -->|fail| X["📝 Logged with reason"]
    H --> A["🚀 Action<br/>publish · apply · send"]
    A --> B["📈 Dashboard & Ledger"]
    X --> B

    classDef brand fill:#1e1b4b,stroke:#7C3AED,stroke-width:2px,color:#e9d5ff;
    classDef gate fill:#083344,stroke:#06B6D4,stroke-width:2px,color:#cffafe;
    class T,D,S,L,H,A,B,X brand;
    class R gate;
```
